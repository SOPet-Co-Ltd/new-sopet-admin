# จัดการร้านค้า

## ภาพรวม

ค้นหา ดู อนุมัติ/ระงับ สร้างร้านแทนเจ้าของ และตั้งค่าคอมมิชชัน รวมแผงเกี่ยวกับการรับเงินของร้าน

![หน้ารายการร้านค้าในพอร์ทัลผู้ดูแล](/help/admin/stores.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

| หน้า       | URL                  |
| ---------- | -------------------- |
| รายการ     | `/admin/stores`      |
| สร้างใหม่  | `/admin/stores/new`  |
| รายละเอียด | `/admin/stores/[id]` |

เมนู: **จัดการ → ร้านค้า**

## ส่วนประกอบหน้ารายการ

- ค้นหา กรอง สถานะ แบ่งหน้า
- เปิดรายละเอียดร้าน

## ส่วนประกอบหน้ารายละเอียด

- ข้อมูลร้านและสถานะ
- เจ้าของร้าน / การเปลี่ยนเจ้าของ (ตามที่ UI รองรับ)
- อัตราค่าคอมมิชชันเฉพาะร้าน
- แผงเกี่ยวกับ Omise / payout

## ขั้นตอน: สร้างร้านโดย Admin

![แบบฟอร์มสร้างร้านค้าโดยผู้ดูแล](/help/admin/stores-new.png)

1. เปิด `/admin/stores/new`
2. เลือกเจ้าของ (ผู้ขาย) และกรอกข้อมูลร้าน
3. บันทึก
4. ตรวจสถานะและการตั้งค่าต่อในหน้ารายละเอียด

## ขั้นตอน: ตั้งค่าคอมมิชชัน

![หน้ารายละเอียดร้านค้า (คอมมิชชันและการตั้งค่า)](/help/admin/stores-detail.png)

1. เปิดหน้าร้าน
2. กำหนดอัตราค่าคอมมิชชัน (0–100%)
3. บันทึก — อัตรานี้ใช้กับยอดสินค้าหลังวันเปิดใช้สูตรตามกฎระบบ ไม่หักจากค่าจัดส่ง

## สถานะร้าน

รออนุมัติ / เปิดใช้งาน / ปฏิเสธแล้ว / ถูกระงับ
