# รหัสข้อผิดพลาด

## ภาพรวม

หน้ารหัสข้อผิดพลาดสำหรับทีมซัพพอร์ต ค้นหาโค้ดข้อผิดพลาดและข้อความภาษาไทย (รวมคำอธิบายเพิ่มเติมบางรายการ)

![ตั้งค่าแพลตฟอร์ม (ลิงก์ไปรหัสข้อผิดพลาด)](/help/admin/settings.png)

## ใครใช้ได้

ผู้ดูแลระบบ และหน้าอาจเข้าถึงในโหมดสาธารณะตามการตั้งค่า route ของระบบ

## วิธีเข้าถึง

`/admin/errors-message` (มักมีลิงก์จากตั้งค่าหรือเอกสารภายใน)

## ขั้นตอนการใช้งาน

1. เปิดหน้า
2. ค้นหาด้วยรหัสข้อผิดพลาดหรือข้อความ
3. ใช้คำอธิบายสื่อสารกับลูกค้า/ผู้ขายอย่างสอดคล้อง

## ลิงก์ที่เกี่ยวข้อง

- หน้าจริง: [/admin/errors-message](/admin/errors-message)
