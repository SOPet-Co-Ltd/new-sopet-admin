# ภาพรวมคู่มือผู้ดูแลระบบ

ยินดีต้อนรับสู่คู่มือการใช้งานพอร์ทัลผู้ดูแลระบบ SOPet

## ภาพรวม

พอร์ทัล Admin ใช้ดูแลตลาดกลางทั้งระบบ: ร้านค้า ผู้ขาย ลูกค้า คิวงานปฏิบัติการ การตลาด การค้นหา อีเมล และการตั้งค่าแพลตฟอร์ม

![หน้าแรกคู่มือผู้ดูแลระบบ](/help/admin/help-index.png)

## ใครใช้ได้

บัญชีบทบาท **ผู้ดูแลระบบ (admin)** เท่านั้น — ผู้ขายเข้า `/admin` ไม่ได้

## วิธีเข้าถึงคู่มือ

เปิดได้โดยไม่ต้องเข้าสู่ระบบที่ [`/guide/admin`](/guide/admin) หรือจากเมนู **บัญชี → คู่มือการใช้งาน** ในพอร์ทัล (จะพาไปคู่มือสาธารณะเดียวกัน)

![หน้าแรกคู่มือสาธารณะ /guide](/help/shared/guide-hub.png)

## โครงสร้างเมนูหลัก

1. **ภาพรวม** — Analytics
2. **จัดการ** — ร้านค้า ผู้ขาย ลูกค้า
3. **คำขอ** — ศูนย์คำขอ, เปิดใช้งานร้าน, รีวิวนำเข้า, โอนเงินเข้าบัญชี, Payout Manual
4. **การตลาด** — โปรโมชัน, หมวดหมู่และแท็ก, การจัดส่ง
5. **การค้นหา** — synonym, จัดอันดับ, วิเคราะห์
6. **ระบบ** — เทมเพลต/คอนเทนเนอร์อีเมล
7. **บัญชี** — audit log, แจ้งเตือน, ตั้งค่า, ทีม, โปรไฟล์, คู่มือ
