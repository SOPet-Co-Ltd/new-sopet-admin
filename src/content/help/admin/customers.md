# จัดการลูกค้า

## ภาพรวม

ค้นหา แก้ไขข้อมูลบัญชีลูกค้า ยืนยันเบอร์โทร จัดการที่อยู่จัดส่ง และดูประวัติคำสั่งซื้อสำหรับงานซัพพอร์ต

![หน้ารายการลูกค้าแพลตฟอร์ม](/help/admin/customers.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **จัดการ → ลูกค้า** (`/admin/customers`) · รายละเอียด `/admin/customers/[id]`

## ขั้นตอนการใช้งาน

1. ค้นหาลูกค้าด้วยเบอร์โทร ชื่อ หรืออีเมล
2. เปิดรายละเอียดแล้วแก้ไขชื่อ อีเมล เบอร์โทร หรือวันเกิด — ล้างช่องว่างแล้วบันทึกเพื่อลบค่าที่ไม่ต้องการ
3. ระงับหรือเปิดใช้งานบัญชีได้จากปุ่มสถานะ
4. หากเบอร์ยังไม่ยืนยัน ให้ใช้ **ยืนยันเบอร์โทรด้วยตนเอง** หลังตรวจสอบตัวตนแล้ว
5. จัดการที่อยู่จัดส่งที่บันทึกไว้ (เพิ่ม / แก้ไข / ลบ / ตั้งค่าเริ่มต้น) จากแผงที่อยู่บนหน้ารายละเอียด
6. ใช้สรุปการซื้อและประวัติออเดอร์ประกอบการแก้ปัญหา (ร่วมกับรหัสข้อผิดพลาดหากจำเป็น)
