# เปิดใช้งานร้าน (Reactivation)

## ภาพรวม

พิจารณาคำขอจากผู้ขายที่ต้องการเปิดร้านที่ถูกระงับอีกครั้ง

![หน้าเปิดใช้งานร้านที่ถูกระงับ](/help/admin/reactivation-requests.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **คำขอ → เปิดใช้งานร้าน** (`/admin/reactivation-requests`)

## ขั้นตอนการใช้งาน

1. เปิดรายการคำขอ
2. อ่านเหตุผลจากผู้ขายและประวัติร้าน
3. อนุมัติเพื่อคืนสถานะเปิดใช้งาน หรือปฏิเสธพร้อมเหตุผล
4. ติดตามว่าผู้ขายกลับมาใช้งานเมนูขายได้
