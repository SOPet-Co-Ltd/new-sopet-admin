# Payout Manual

## ภาพรวม

คิวคำขอรับเงินจากร้านค้า (ทุกช่องทางชำระเงิน) ให้ทีม Admin ตรวจสอบยอดคอมมิชชัน โอนเงินเข้าบัญชีร้านที่ผ่านการตรวจสอบแล้ว จากนั้นทำเครื่องหมายว่าโอนแล้วหรือปฏิเสธ

![คิว Payout Manual](/help/admin/manual-payouts.png)

## ใครใช้ได้

ผู้ดูแลระบบ / ทีมการเงิน

## วิธีเข้าถึง

เมนู **คำขอ → Payout Manual** (`/admin/manual-payouts`) — มี badge จำนวนค้าง

## ส่วนประกอบหน้าจอ

- รายการคำขอรอพิจารณา
- รายละเอียดยอด: ยอดสินค้า ค่าจัดส่ง ค่าคอมมิชชันหัก ยอดสุทธิที่ต้องโอน
- การกระทำ: ยืนยันโอนแล้ว / ปฏิเสธ

## ขั้นตอนปฏิบัติ

1. **ตรวจสอบบัญชีธนาคารของร้าน** ที่หน้ารายละเอียดร้าน (`/admin/stores/[id]`) แล้วกด **ยืนยันบัญชี** หรือ **ปฏิเสธบัญชี** (ต้องระบุเหตุผล) — ร้านจะขอรับเงินได้เมื่อบัญชีผ่านการตรวจสอบเท่านั้น
2. ร้านกด **ขอรับเงิน** — คำขอจะเข้าคิวในหน้านี้
3. เปิดคำขอและตรวจรายละเอียดยอด
4. โอนเงินจริงไปยังบัญชีร้านตามยอดสุทธิ
5. กลับมากดยืนยันในระบบ (ปิดรอบ)
6. หากข้อมูลบัญชีผิดหรือมียอดไม่ถูกต้อง ให้ปฏิเสธคำขอ

## ความจำเกี่ยวกับคอมมิชชัน

- หักจากยอดสินค้า ไม่หักค่าจัดส่ง
- ยอดที่ถูกบันทึกตอนขอรับเงินแล้ว จะไม่ถูกกระทบจากการเปลี่ยนอัตราภายหลัง
