# Payout Manual

## ภาพรวม

คิวคำขอรับเงินแบบ Manual จากร้านค้า (นอกรอบโอนอัตโนมัติผ่าน Omise) ให้ทีม Admin ตรวจสอบยอดคอมมิชชัน แล้วทำเครื่องหมายว่าโอนแล้วหรือปฏิเสธ

![คิว Payout Manual](/help/admin/manual-payouts.png)

## ใครใช้ได้

ผู้ดูแลระบบ / ทีมการเงิน

## วิธีเข้าถึง

เมนู **คำขอ → Payout Manual** (`/admin/manual-payouts`) — มี badge จำนวนค้าง

## ส่วนประกอบหน้าจอ

- รายการคำขอรอพิจารณา
- รายละเอียดยอด: ยอดสินค้า ค่าจัดส่ง ค่าคอมมิชชันหัก ยอดสุทธิที่ต้องโอน
- การกระทำ: ยืนยันโอนแล้ว / ปฏิเสธ

## ขั้นตอนปฏิบัติ

1. เปิดคำขอและตรวจรายละเอียดยอด
2. โอนเงินจริงไปยังบัญชีร้านตามยอดสุทธิ
3. กลับมากดยืนยันในระบบ
4. หากข้อมูลบัญชีผิดหรือมียอดไม่ถูกต้อง ให้ปฏิเสธพร้อมเหตุผล

## ความจำเกี่ยวกับคอมมิชชัน

- หักจากยอดสินค้า ไม่หักค่าจัดส่ง
- ยอดที่ถูกบันทึกตอนขอรับเงินแล้ว จะไม่ถูกกระทบจากการเปลี่ยนอัตราภายหลัง
