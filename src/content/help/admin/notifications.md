# การแจ้งเตือน

## ภาพรวม

ศูนย์การแจ้งเตือนในแอปสำหรับผู้ดูแล เช่น คำขอใหม่ งานคิว และเหตุการณ์ระบบ

![หน้าการแจ้งเตือนผู้ดูแล](/help/admin/notifications.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **บัญชี → การแจ้งเตือน** (`/admin/notifications`) — มี badge ยังไม่อ่าน

## ขั้นตอนการใช้งาน

1. เปิดรายการแจ้งเตือน
2. อ่านรายการยังไม่อ่าน
3. กดไปยังหน้างานที่เกี่ยวข้อง
4. เคลียร์คิวงานให้ badge ลดลง
