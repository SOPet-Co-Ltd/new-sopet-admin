# ปรับการจัดอันดับการค้นหา

## ภาพรวม

ปรับน้ำหนักคะแนนที่ส่งผลต่อการเรียงลำดับผลค้นหา เช่น ความสำคัญของการจับคู่ข้อความ หรือการขึ้นต้นด้วยคำค้น

![หน้าปรับการจัดอันดับการค้นหา](/help/admin/search-tuning.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **การค้นหา → ปรับการจัดอันดับ** (`/admin/search/tuning`)

## ขั้นตอนการใช้งาน

1. เปิดหน้าปรับน้ำหนัก
2. อ่านคำอธิบายของแต่ละสไลเดอร์/ฟิลด์
3. ปรับทีละน้อยแล้วบันทึก
4. ทดสอบคำค้นจริงบนหน้าร้าน
5. ใช้หน้าวิเคราะห์การค้นหาเพื่อประเมินผล

## ข้อควรระวัง

- อย่าเปลี่ยนหลายพารามิเตอร์พร้อมกันโดยไม่จดค่าเดิม
- หลังปรับ ควรเฝ้าดู zero-result queries
