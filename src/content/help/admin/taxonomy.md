# หมวดหมู่และแท็ก

## ภาพรวม

จัดการโครงสร้างสินค้า: หมวดหมู่ แท็ก ประเภทสัตว์เลี้ยง และแบรนด์ รวมคิวข้อเสนอจากผู้ขายที่รออนุมัติ

![หน้าหมวดหมู่และแท็ก](/help/admin/taxonomy.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **การตลาด → หมวดหมู่และแท็ก** (`/admin/taxonomy`) — badge รวมรายการรออนุมัติ

แก้ไขรายการ:

- `/admin/taxonomy/categories/[id]/edit`
- `/admin/taxonomy/tags/[id]/edit`
- `/admin/taxonomy/pet-types/[id]/edit`
- `/admin/taxonomy/brands/[id]/edit`

## ส่วนประกอบหน้าจอ

- แท็บหรือส่วนสำหรับแต่ละชนิด taxonomy
- คิว **รออนุมัติ** จากผู้ขาย
- สร้าง/แก้ไขรายการที่อนุมัติแล้ว

## ขั้นตอน: อนุมัติข้อเสนอจากผู้ขาย

1. เปิดหน้า taxonomy
2. ไปที่คิวรออนุมัติ
3. ตรวจชื่อซ้ำและความเหมาะสม
4. อนุมัติหรือปฏิเสธ

## สถานะ

รออนุมัติ / อนุมัติแล้ว / ปฏิเสธแล้ว
