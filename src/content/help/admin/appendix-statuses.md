# ภาคผนวก: สถานะและความหมาย (ผู้ดูแล)

## สถานะร้าน

| รหัส      | ภาษาไทย    |
| --------- | ---------- |
| pending   | รออนุมัติ  |
| approved  | เปิดใช้งาน |
| rejected  | ปฏิเสธแล้ว |
| suspended | ถูกระงับ   |

## สถานะคำขอเปิดร้าน / taxonomy

รออนุมัติ / อนุมัติแล้ว / ปฏิเสธแล้ว

## สถานะคำสั่งซื้อ / การจัดส่ง / การชำระเงิน

ใช้ตารางเดียวกับฝั่งผู้ขาย — ดูสรุปใน [อภิธานศัพท์](/guide/admin/glossary) หรือหน้าคู่มือผู้ขายภาคผนวกสถานะ หากต้องการรายละเอียดครบ

## ประเภทโปรโมชัน

ส่วนลดเปอร์เซ็นต์, ส่วนลดคงที่, จัดส่งฟรี, ซื้อ X แถม Y, ส่วนลดค่าจัดส่งคงที่, ส่วนลดค่าจัดส่งเปอร์เซ็นต์

## บทบาทสมาชิกร้าน (อ้างอิงเมื่อซัพพอร์ตผู้ขาย)

| บทบาท     | สิทธิ์                                               |
| --------- | ---------------------------------------------------- |
| เจ้าของ   | จัดการทีม รับเงิน ตั้งค่าร้าน และสิทธิ์ทั้งหมด       |
| ผู้จัดการ | จัดการ API และงานขายทั่วไป — ไม่จัดการทีมหรือรับเงิน |
| พนักงาน   | งานขายทั่วไป เช่น สินค้า คำสั่งซื้อ และโปรโมชัน      |
