# คำพ้องความหมาย (Search)

## ภาพรวม

กำหนดคำพ้องสำหรับ Smart Search เพื่อให้คำค้นต่างกันชี้ไปผลลัพธ์เดียวกัน (เช่น คำย่อ / คำสะกดต่าง)

![หน้าจัดการคำพ้องความหมาย](/help/admin/search-synonyms.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **การค้นหา → คำพ้องความหมาย** (`/admin/search/synonyms`)

## ขั้นตอนการใช้งาน

1. เปิดหน้าคำพ้อง
2. เพิ่มกลุ่มคำที่ควรเทียบเท่ากัน
3. บันทึก
4. ทดสอบค้นหาบนหน้าร้าน

## ข้อควรระวัง

- หลีกเลี่ยงการผูกคำที่ไม่เกี่ยวข้องกัน ซึ่งจะทำให้ผลค้นหาเพี้ยน
