# ศูนย์คำขอ

## ภาพรวม

ศูนย์ปฏิบัติการสำหรับ (1) คำขอเปิดร้านที่รออนุมัติ และ (2) การเชิญผู้ขายใหม่เข้าแพลตฟอร์ม รวมประวัติที่เกี่ยวข้อง

![หน้าศูนย์คำขอ — อนุมัติร้านและเชิญผู้ขาย](/help/admin/requests.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **คำขอ → ศูนย์คำขอ** (`/admin/requests`) — มี badge รวมจำนวนค้าง

## ส่วนประกอบหน้าจอ

- แท็บ/ส่วนคำขอเปิดร้าน: อนุมัติ / ปฏิเสธ / ดูประวัติ
- ส่วนเชิญผู้ขายใหม่: ส่งคำเชิญทางอีเมล
- รายการคำเชิญที่รอการตอบรับ

## ขั้นตอน: อนุมัติคำขอเปิดร้าน

1. เปิดศูนย์คำขอ
2. ตรวจข้อมูลร้านและผู้ขอ
3. กดอนุมัติ หรือปฏิเสธพร้อมเหตุผล
4. แจ้งผลผ่านระบบ (ผู้ขายเห็นสถานะในพอร์ทัล)

## ขั้นตอน: เชิญผู้ขายใหม่

1. ในส่วนเชิญผู้ขาย กรอกอีเมล
2. ส่งคำเชิญ
3. ผู้ขายลงทะเบียนผ่าน `/register/invite`
