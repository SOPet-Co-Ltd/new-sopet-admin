# โปรไฟล์

## ภาพรวม

แก้ไขชื่อแสดงผลและรหัสผ่านของบัญชีผู้ดูแลที่ล็อกอินอยู่

![หน้าโปรไฟล์ผู้ดูแล](/help/admin/profile.png)

## ใครใช้ได้

ผู้ดูแลระบบทุกคน สำหรับบัญชีของตนเอง

## วิธีเข้าถึง

เมนู **บัญชี → โปรไฟล์** (`/admin/profile`)

## ขั้นตอนการใช้งาน

1. แก้ชื่อแล้วบันทึก
2. เปิดส่วนเปลี่ยนรหัสผ่าน กรอกรหัสปัจจุบันและรหัสใหม่
3. ยืนยันการบันทึก

## ลิงก์ที่เกี่ยวข้อง

- หน้าจริง: [/admin/profile](/admin/profile)
