# ทีมผู้ดูแล

## ภาพรวม

เชิญผู้ดูแลใหม่ เปิด/ปิดใช้งานบัญชี และเพิกถอนคำเชิญของทีม Admin

![หน้าทีมผู้ดูแล](/help/admin/team.png)

## ใครใช้ได้

ผู้ดูแลระบบ (ควรจำกัดเฉพาะผู้ที่ได้รับมอบหมาย)

## วิธีเข้าถึง

เมนู **บัญชี → ทีมผู้ดูแล** (`/admin/team`)

## สิทธิ์โดยสรุปของ Admin

อนุมัติร้านค้า จัดการงานปฏิบัติการ ตั้งค่าแพลตฟอร์ม และเชิญผู้ดูแลคนอื่น

## ขั้นตอน: เชิญผู้ดูแล

1. เปิดหน้าทีมผู้ดูแล
2. กรอกอีเมลและส่งคำเชิญ
3. ผู้รับลงทะเบียนผ่าน `/register/invite/admin`
4. ตรวจสถานะคำเชิญจนกว่าจะตอบรับ

## ขั้นตอน: ปิดใช้งานสมาชิก

1. เลือกรายชื่อในทีม
2. ปิดใช้งานตามนโยบายความปลอดภัยเมื่อพนักงานออกหรือเปลี่ยนบทบาท
