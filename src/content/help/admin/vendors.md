# จัดการผู้ขาย

## ภาพรวม

ดูบัญชีผู้ขาย รายละเอียดร้านที่เป็นสมาชิก กิจกรรม และเครื่องมือช่วยเหลือ เช่น ยืนยันอีเมล / รีเซ็ตรหัสผ่าน

![หน้ารายการผู้ขาย](/help/admin/vendors.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **จัดการ → ผู้ขาย** (`/admin/vendors`) · รายละเอียด `/admin/vendors/[id]`

## ส่วนประกอบหน้าจอ

- รายการค้นหาผู้ขาย
- หน้ารายละเอียด: โปรไฟล์ สมาชิกร้าน ประวัติกิจกรรม
- การกระทำช่วยเหลือบัญชี (ส่งยืนยันอีเมล / รีเซ็ตรหัสผ่าน ตามที่ระบบมี)

## ขั้นตอนการใช้งาน

1. ค้นหาผู้ขายด้วยอีเมลหรือชื่อ
2. เปิดรายละเอียด
3. ตรวจร้านที่เกี่ยวข้องและสถานะ
4. ใช้เครื่องมือช่วยเหลือเมื่อผู้ขายติดปัญหาเข้าสู่ระบบหรือยืนยันอีเมล

![หน้ารายละเอียดผู้ขาย](/help/admin/vendors-detail.png)
