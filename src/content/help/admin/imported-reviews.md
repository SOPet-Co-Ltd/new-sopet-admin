# รีวิวนำเข้า

## ภาพรวม

คิวอนุมัติรีวิวที่นำเข้าผ่าน Vendor API ก่อนแสดงบนหน้าร้าน (มักแสดงในฐานะลูกค้าแบบไม่ระบุตัวตนตามกฎระบบ)

![คิวอนุมัติรีวิวนำเข้า](/help/admin/imported-reviews.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **คำขอ → รีวิวนำเข้า** (`/admin/reviews`) — มี badge จำนวนค้าง

## ขั้นตอนการใช้งาน

1. เปิดคิวรีวิวนำเข้า
2. อ่านเนื้อหา คะแนน และสินค้าที่เกี่ยวข้อง
3. อนุมัติรายการที่เหมาะสม หรือปฏิเสธรายการที่ไม่ผ่านนโยบาย
4. ตรวจว่า badge ลดลงหลังเคลียร์คิว

## ข้อควรระวัง

- ตรวจสแปม เนื้อหาไม่เหมาะสม หรือรีวิวที่ไม่เกี่ยวกับสินค้า

## ลิงก์ที่เกี่ยวข้อง

- หน้าจริง: [/admin/reviews](/admin/reviews)
