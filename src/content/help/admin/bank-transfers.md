# โอนเงินเข้าบัญชี

## ภาพรวม

เมื่อลูกค้าเลือกชำระด้วย **โอนเงินเข้าบัญชี** ออเดอร์จะรอให้ทีม Ops ตรวจยอดเข้าบัญชีกลางของ SOPet แล้วกดยืนยันในหน้านี้

![หน้ายืนยันโอนเงินเข้าบัญชี](/help/admin/bank-transfers.png)

## ใครใช้ได้

ผู้ดูแลระบบ / ทีมปฏิบัติการการเงิน

## วิธีเข้าถึง

เมนู **คำขอ → โอนเงินเข้าบัญชี** (`/admin/bank-transfers`) — มี badge จำนวนค้าง

บัญชีรับโอนของแพลตฟอร์มตั้งที่ **ตั้งค่าแพลตฟอร์ม → บัญชีรับโอน**

## ขั้นตอนการยืนยันการชำระ

1. ตรวจ statement / ยอดเข้าบัญชีจริง
2. เปิดหน้าโอนเงินเข้าบัญชี
3. จับคู่ออเดอร์กับยอด (จำนวนเงิน เวลา อ้างอิง)
4. กดยืนยันการชำระสำหรับออเดอร์ที่ตรง
5. ผู้ขายจะดำเนินการจัดส่งต่อได้เมื่อสถานะพร้อม

## ข้อควรระวัง

- อย่ายืนยันหากยอดไม่ตรงหรือหลักฐานไม่ชัด
- ตรวจการตั้งค่าบัญชีรับโอนให้เป็นปัจจุบันก่อนสื่อสารกับลูกค้า
