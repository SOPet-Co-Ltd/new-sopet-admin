# ตั้งค่าแพลตฟอร์ม

## ภาพรวม

ตั้งค่าคอนเทนต์และการดำเนินงานของหน้าร้าน/แพลตฟอร์มผ่านแท็บต่างๆ

![หน้าตั้งค่าแพลตฟอร์ม](/help/admin/settings.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **บัญชี → ตั้งค่าแพลตฟอร์ม** (`/admin/settings`)

## แท็บที่มี

| แท็บ               | ใช้ทำอะไร                                                        |
| ------------------ | ---------------------------------------------------------------- |
| แบนเนอร์           | จัดการแบนเนอร์หน้าร้าน                                           |
| สปอนเซอร์          | โลโก้/ลิงก์สปอนเซอร์                                             |
| โฆษณาป๊อปอัพ       | ป๊อปอัพโปรโมต                                                    |
| รูปหน้าเข้าสู่ระบบ | ภาพประกอบหน้า login ของพอร์ทัล                                   |
| บัญชีรับโอน        | บัญชีกลางสำหรับลูกค้าโอนเงิน                                     |
| หน้าร้าน           | รวมโหมดปิดปรับปรุง (maintenance) และตั้งค่าหน้าร้านที่เกี่ยวข้อง |

![แท็บแบนเนอร์ในตั้งค่าแพลตฟอร์ม](/help/admin/settings-banners.png)

![แท็บบัญชีรับโอน](/help/admin/settings-bank-transfer.png)

![แท็บหน้าร้าน / โหมดปิดปรับปรุง](/help/admin/settings-storefront.png)

## ขั้นตอนทั่วไป

1. เลือกแท็บที่ต้องการ
2. เพิ่ม/แก้ไขรายการ พร้อมช่วงเวลาเปิดใช้ (ถ้ามี)
3. เปิด/ปิดสถานะ active
4. บันทึกและตรวจบนหน้าร้าน

## ข้อควรระวัง

- โหมดปิดปรับปรุงจะกระทบลูกค้า — สื่อสารล่วงหน้า
- บัญชีรับโอนต้องตรงกับบัญชีจริงที่ใช้กระทบยอดใน [โอนเงินเข้าบัญชี](/guide/admin/bank-transfers)
