# วิเคราะห์การค้นหา

## ภาพรวม

ดูสถิติการค้นหา เช่น คำค้นยอดนิยม คำที่ไม่มีผลลัพธ์ และ CTR ตาม prefix เพื่อปรับปรุง synonym และ ranking

![หน้าวิเคราะห์การค้นหา](/help/admin/search-analytics.png)

## ใครใช้ได้

ผู้ดูแลระบบ

## วิธีเข้าถึง

เมนู **การค้นหา → วิเคราะห์การค้นหา** (`/admin/search/analytics`)

## ขั้นตอนการใช้งาน

1. เปิดหน้าวิเคราะห์
2. ตรวจคำที่ zero-result — พิจารณาเพิ่ม synonym หรือสินค้า/หมวด
3. ตรวจคำยอดนิยมว่าผลลัพธ์คุณภาพดีหรือไม่
4. กลับไปปรับ synonym/tuning ตามข้อมูล
