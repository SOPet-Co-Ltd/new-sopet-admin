# เริ่มต้นใช้งานและเข้าสู่ระบบ

## ภาพรวม

วิธีเข้าสู่ระบบ Admin, รีเซ็ตรหัสผ่าน, และรับคำเชิญเข้าร่วมทีมผู้ดูแล

![หน้าเข้าสู่ระบบ](/help/shared/login.png)

## ใครใช้ได้

ผู้ดูแลระบบที่ได้รับบัญชีหรือคำเชิญแล้ว

## วิธีเข้าถึง

| การทำงาน           | URL                                                                |
| ------------------ | ------------------------------------------------------------------ |
| เข้าสู่ระบบ        | `/login`                                                           |
| รับคำเชิญทีม Admin | `/register/invite/admin`                                           |
| รีเซ็ตรหัสผ่าน     | `/reset-password?token=...`                                        |
| หลังเข้าสู่ระบบ    | มักพาไปแดชบอร์ด Admin เช่น `/admin/stores` หรือ `/admin/analytics` |

## ขั้นตอน: เข้าสู่ระบบ

1. เปิด `/login`
2. กรอกอีเมลและรหัสผ่านของบัญชี admin
3. ระบบจะพาเข้าพอร์ทัล Admin

## ขั้นตอน: รับคำเชิญทีมผู้ดูแล

1. ผู้ดูแลคนอื่นเชิญจากหน้า **ทีมผู้ดูแล**
2. เปิดอีเมลเชิญ แล้วไปที่ `/register/invite/admin`
3. ตั้งรหัสผ่าน/ข้อมูลตามแบบฟอร์ม
4. เข้าสู่ระบบ

## ลืมรหัสผ่าน

ใช้ฟังก์ชันลืมรหัสผ่านที่หน้า login จากนั้นตั้งรหัสใหม่จากลิงก์ในอีเมล

![ฟอร์มลืมรหัสผ่าน](/help/shared/forgot-password.png)

## ข้อควรระวัง

- บัญชี vendor ไม่สามารถเข้าโซน `/admin` ได้
- เก็บรหัสผ่านให้ปลอดภัย และใช้ทีมผู้ดูแลอย่างจำกัดสิทธิ์ตามความจำเป็น
