# อภิธานศัพท์

คำอธิบายคำศัพท์ที่ใช้บ่อยในพอร์ทัล Admin และ Vendor ของ SOPet

![ศูนย์รวมคู่มือ SOPet](/help/shared/guide-hub.png)

| คำศัพท์                              | ความหมาย                                                              |
| ------------------------------------ | --------------------------------------------------------------------- |
| **แพลตฟอร์ม (Platform)**             | ระบบตลาดกลาง SOPet ทั้งหน้าร้านลูกค้าและพอร์ทัลหลังบ้าน               |
| **พอร์ทัลผู้ดูแล (Admin)**           | ระบบสำหรับทีม SOPet จัดการร้าน ผู้ขาย การเงิน และการตั้งค่ากลาง       |
| **พอร์ทัลผู้ขาย (Vendor)**           | ระบบสำหรับร้านค้าจัดการสินค้า คำสั่งซื้อ โปรโมชัน และรับเงิน          |
| **ร้านค้า (Store)**                  | หน่วยขายหนึ่งร้านภายใต้บัญชีผู้ขาย อาจมีหลายร้านต่อบัญชี              |
| **เจ้าของ (Owner)**                  | บทบาทสูงสุดของร้าน — จัดการทีม รับเงิน และตั้งค่าร้าน                 |
| **ผู้จัดการ (Manager)**              | จัดการงานขายและ API ได้ แต่ไม่จัดการทีม/รับเงิน                       |
| **พนักงาน (Staff)**                  | ทำงานขายทั่วไป เช่น สินค้า คำสั่งซื้อ โปรโมชัน                        |
| **SKU / ตัวแปรสินค้า (Variant)**     | หน่วยขายย่อยของสินค้า เช่น สี×ขนาด แต่ละรายการมีราคาและสต็อกของตัวเอง |
| **โปรโมชัน (Promotion)**             | โค้ดส่วนลดที่ใช้ตอนชำระเงิน                                           |
| **แคมเปญ (Campaign)**                | การลดราคาที่แสดงบนหน้าร้าน (ราคาที่ลูกค้าเห็น)                        |
| **คอมมิชชัน (Commission)**           | ค่าธรรมเนียมแพลตฟอร์มหักจากยอดสินค้าตอนขอรับเงิน                      |
| **Payout / รับเงิน**                 | การโอนยอดสุทธิจากแพลตฟอร์มไปยังบัญชีร้าน                              |
| **Payout Manual**                    | การรับเงินนอกระบบ Omise โดยทีม Admin ยืนยันการโอนเอง                  |
| **โอนเงินเข้าบัญชี (Bank transfer)** | วิธีชำระเงินของลูกค้าที่โอนเข้าบัญชีกลางของ SOPet                     |
| **Taxonomy**                         | โครงสร้างหมวดหมู่ แท็ก ประเภทสัตว์เลี้ยง และแบรนด์                    |
| **Smart Search**                     | ระบบค้นหาสินค้าของหน้าร้าน พร้อม synonym และการจัดอันดับ              |
| **Store hold / on hold**             | การพักดำเนินการคำสั่งซื้อชั่วคราว                                     |
| **Reactivation**                     | คำขอเปิดใช้งานร้านที่ถูกระงับอีกครั้ง                                 |
